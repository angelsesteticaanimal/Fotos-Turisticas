Foto Turismo V3.0 — teste de recorte online

Esta versão envia a foto para a API remove.bg e recebe de volta um PNG transparente somente com a pessoa recortada.

Como testar:
1. Crie uma conta no remove.bg.
2. Copie sua API Key nas configurações da conta.
3. Publique todos os arquivos desta pasta na raiz do repositório GitHub Pages.
4. Abra o app, escolha "Recorte online IA".
5. Cole a chave no campo indicado.
6. Fotografe ou selecione uma imagem.
7. Toque em "Recortar pela IA online".

Segurança:
- A chave não está dentro dos arquivos do aplicativo.
- Ela é salva somente no armazenamento local do navegador usado no teste.
- Para uso público/comercial, o ideal é criar um pequeno backend/proxy para ocultar a chave.

Observação:
- A foto é enviada para o serviço online de remoção de fundo.
- É necessário acesso à internet.
